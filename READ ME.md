comandos de git

git init: inicia el proyecto git

git add: añadir archivos al proyecto git

git status: checkea que archivos estan en el proyecto

git config user.email "correo aquí"

git config user.name "nombre aquí"

git commit -m "Nombre de versión"

como añadir estilos:
para añadir estilos se necesita un archivo css que tenga información de la página y especificar sus estilos y juntarlo al git como los otros documentos
