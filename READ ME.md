comandos de git

git init: inicia el proyecto git

git add: añadir archivos al proyecto git

git status: checkea que archivos estan en el proyecto

git config user.email "correo aquí"

git config user.name "nombre aquí"

git commit -m "Nombre de versión"

como añadir estilos:
para añadir estilos se necesita un archivo css que tenga información de la página y especificar sus estilos y juntarlo al git como los otros documentos

JavaScript:
el JavaScript ofrece una funcionalidad al HTML. En este caso hace que al hacer clic en alguno de los personajes se muestra una pequeña pestaña con su descripción.

Compatibilidad con otros dispositivos:
Se usaron media queries para adaptar los tamaños de fuente, anchos de .character, y el padding en dispositivos pequeños.
Las imágenes usan max-width: 100% para que no desborden su contenedor.
.character pasa de inline-block a block en móviles para mejorar la visualización vertical.
